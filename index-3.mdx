title: "PB: Engagement Detail"
description: "The purpose of this flow is to ensure the Current Year and Current Month fields on the Engagement Detail entity are accurate. If an engagement detail record's Activity Date is in the current year, Current Year should say yes. If the Activity Date is in the current month, Current Month should say yes. If the activity falls outside the current month or current year, the corresponding field should say no."
mode: "wide"
---

import { FlowCard } from '/app.jsx'
import { FlowInput } from '/app.jsx'

<FlowCard title="Runs Once Daily" type="schedule" step="1">
  This flow runs on a schedule once every day at 10am.
</FlowCard>

<br />

<FlowCard title="HTTP Get Engagement Details" type="get" step="2">
  An HTTP request is made to the NAMIC Protech TDS Connector web API. This API returns the Engagement Detail records that need to be updated in JSON format.

  <FlowInput title="Method">GET</FlowInput>
  <FlowInput title="URL">[https://namicprotecttdsconnectorprod-eagvdxdzaxhzh4g8.northcentralus-01.azurewebsites.net/Search/Engagement/GetDetails](https://namicprotecttdsconnectorprod-eagvdxdzaxhzh4g8.northcentralus-01.azurewebsites.net/Search/Engagement/GetDetails)</FlowInput>
</FlowCard>

The API executes the following SQL query to identify records where the Current Year or Current Month fields need to be updated.

```sql
SELECT
    pa_engagementdetailid,
    pa_activitydate,

    CASE
        WHEN YEAR(pa_activitydate) = YEAR(GETDATE()) AND namic_currentyear <> 1 THEN 'true'
        WHEN YEAR(pa_activitydate) <> YEAR(GETDATE()) AND namic_currentyear = 1 THEN 'false'
        ELSE CASE WHEN namic_currentyear = 1 THEN 'true' ELSE 'false' END
    END AS updateYearTo,

    CASE
        WHEN YEAR(pa_activitydate) = YEAR(GETDATE())
        AND MONTH(pa_activitydate) = MONTH(GETDATE())
        AND namic_currentmonth <> 1 THEN 'true'

        WHEN (YEAR(pa_activitydate) <> YEAR(GETDATE()) OR MONTH(pa_activitydate) <> MONTH(GETDATE()))
        AND namic_currentmonth = 1 THEN 'false'

        ELSE CASE WHEN namic_currentmonth = 1 THEN 'true' ELSE 'false' END
    END AS updateMonthTo

FROM pa_engagementdetail

WHERE
(
    (YEAR(pa_activitydate) = YEAR(GETDATE()) AND namic_currentyear <> 1)
    OR (YEAR(pa_activitydate) <> YEAR(GETDATE()) AND namic_currentyear = 1)

    OR (YEAR(pa_activitydate) = YEAR(GETDATE())
    AND MONTH(pa_activitydate) = MONTH(GETDATE())
    AND namic_currentmonth <> 1)

    OR ((YEAR(pa_activitydate) <> YEAR(GETDATE())
    OR MONTH(pa_activitydate) <> MONTH(GETDATE()))
    AND namic_currentmonth = 1)
);
```

The request returns a JSON array containing all Engagement Detail records that require an update.

For example, the first record below has an Activity Date outside the current month and year, so both fields are set to false. The second record falls within the current month and year, so both fields are set to true.

```json
[
  {
    "pa_engagementdetailid": "ece2d25f-f285-ef11-ac21-00224826e1e2",
    "pa_activitydate": "2025-02-13T07:55:56",
    "updateYearTo": "false",
    "updateMonthTo": "false"
  },
  {
    "pa_engagementdetailid": "0c2b9c88-1114-f111-8407-6045bdec5c95",
    "pa_activitydate": "2026-02-18T05:00:00",
    "updateYearTo": "true",
    "updateMonthTo": "true"
  }
]
```

<br />

<FlowCard title="Bulk Update API" type="scope" step="3">
  The JSON array returned by the previous step is passed into the Bulk Update API. This API processes each Engagement Detail record and updates its Current Year and Current Month fields based on the `updateYearTo` and `updateMonthTo` values.

  The following Dataverse fields are updated:

  <FlowInput title="Current Year">namic_currentyear</FlowInput>
  <FlowInput title="Current Month">namic_currentmonth</FlowInput>
</FlowCard>

Each record is updated individually using its `pa_engagementdetailid` to identify the corresponding Engagement Detail record.
